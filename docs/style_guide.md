## Palette
| Token  | Hex      | Use |
|--------|----------|-----|
| ink    | #0d0d0c  | primary background, type on paper |
| paper  | #efece4  | type on ink, contrast panels |
| accent | #ff4a1c  | one accent only: the key word, the active state, the mark |
| mute   | #8c897f  | secondary labels |

## Typography
- Display: Helvetica Neue 800–900, tracking −0.04 to −0.055em, sized to fill the frame width.
- Mono: SF Mono / Menlo for code, numbers, labels. Minimum 3.4U for anything that must be read.

## Motion language
- Type enters character-by-character from below a mask; exits upward with ease-in.
- Large type: `heavy` spring. Important text: `text` spring (no overshoot). UI: `ui` / `snappy`.
- Transitions are physical (wipes, morphs, an object growing to fill the frame), never crossfades.
- Camera: slow push-ins (≤7%) during holds; settles, never drifts endlessly.

## Pacing
- Hook within 2s. A new visual event every 2–4s. Shot length 2–5s.
